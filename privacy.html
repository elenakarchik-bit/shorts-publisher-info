Privacy policy

Effective date: October 13, 2026.

Telegram YouTube Test is a personal publishing tool operated by the owner of this repository.

Data accessed and purpose

The tool accesses selected Telegram group/topic messages, videos, captions, and message identifiers using the operator's authorized Telegram account. Google authorization permits the tool to identify the authorized YouTube channel and upload videos, titles, descriptions, and audience/privacy settings to that channel. The tool does not request Gmail, contacts, or Google Drive access.

Storage and services

During local testing, downloaded videos, captions, channel information, upload results, Telegram sessions, and Google authorization tokens are stored on the operator's computer. For scheduled operation, program code and queue/upload status will be stored in a private GitHub repository, credentials will be stored in GitHub Actions Secrets, and selected media will be processed on GitHub-hosted runners. Media is sent to YouTube for hosting. Publication visibility is controlled by the operator.

This public information repository contains no credentials or video queue. The tool does not sell data, use it for advertising, send it to an AI model, or use it to train AI models. GitHub, Google/YouTube, and Telegram process data required to provide their respective services under their own policies.

Retention and control

Local files remain until deleted by the operator. Queue and upload identifiers are retained to prevent duplicate publication. Temporary runner files last for the job; any retained artifacts or logs are subject to the configured GitHub retention period. Credentials remain until deleted or revoked. Uploaded videos remain on YouTube until removed by the channel owner.

The operator can stop scheduled workflows, remove GitHub Secrets, delete local files and queue records, revoke Google access in Google Account settings, and terminate the Telegram session in Telegram settings. Deleting local files does not delete uploaded YouTube videos.

Google API user data

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Contact through repository issues. Do not include secrets or private content in public issues.
